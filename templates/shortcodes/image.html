{#- General image shortcode. Usage in markdown: {{ image(src="memory.svg") }} # asset colocated in the project section {{ image(src="./memory.svg") }} # same — a leading ./ is stripped {{ image(src="clients/placeholder.svg") }} # file under static/ {{ image(src="https://example.com/x.png") }} # external URL {{ image(src="memory.svg", caption="A diagram", alt="...", width="70%") }} - src : required. Bare filename = asset colocated with the current section (resolved to the section URL even when used in a post); path with "/" = under static/; "http..." or "/..." used as-is. - alt : accessibility text (defaults to caption, then ""). - caption : optional
