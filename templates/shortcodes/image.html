{#- General image shortcode. Usage in markdown: {{ image(src="memory.svg") }} # colocated next to the page {{ image(src="clients/placeholder.svg") }} # file under static/ {{ image(src="https://example.com/x.png") }} # external URL {{ image(src="memory.svg", caption="A diagram", alt="...", width="70%") }} - src : required. Bare filename = colocated asset; path with "/" = under static/; "http..." or "/..." used as-is. - alt : accessibility text (defaults to caption, then ""). - caption : optional
